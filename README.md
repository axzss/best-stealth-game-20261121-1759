**The Gilded Shadow** — an original top-down stealth game: you are Wren, thief of the night, stealing the Moon Opal from Lord Ashford's manor unseen. Three levels (Garden Gate, Grand Hall, the Vault) with patrolling guards and vision cones that change colour with suspicion, a detection meter per guard, bushes and darkness as cover, lamp pools that give you away, coin throws to distract, locked doors and brass keys, footstep ripples guards can hear, and synthesized WebAudio sound (footsteps, "huh?" blips, alarm stings, coin pings) — no files, no network, no build step. Fully offline.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` from any static server. `WASD` / arrows to move, `Shift` to sneak, click or `F` to toss a coin, `E` to pocket loot, `P` to pause, `M` to mute. Screenshot states: `?shot=title|play|coin|win&seed=`.
